## ✨ Tutorial Highlights

- **🌱 The web's first systematic open-source AI Agent tutorial**: This is a long-term maintained LLM application development roadmap. There is no shortage of scattered posts or paid bootcamps, but truly systematic, continuously updated AI LLM application tutorials that cover **tutorials + source code + hands-on projects + interview question banks** are extremely rare. What this repository aims to do is make this path public, deep, and complete, growing with you from beginner to advanced to real project practice.
- **🧭 One path through the full LLM application stack**: From LLMs and prompts, to low-code platforms (Coze/Dify) and code frameworks (LangChain/LangGraph), to enterprise-level RAG/Agent, fine-tuning, and engineering standards—organized uniformly by knowledge system, forming a **complete end-to-end** closed loop, suitable for systematic mastery rather than fragmented bookmarking.
- **🐍 Focused on the Python ecosystem, targeting Agent engineering directly**: Many courses revolve around **Spring AI** and **langchain4j**, leaning more toward the Java tech stack. This tutorial focuses on **Python + LangChain + LangGraph**, directly aligning with the most common engineering path for AI Agent / LLM application development today.
- **📘 Beginners can enter, engineers can dig deeper**: The entire tutorial is arranged **from shallow to deep**, first thoroughly explaining core concepts like LLMs, Agents, RAG, MCP, and Tool Calling, then moving into source code, frameworks, deployment, and project design. Less jargon, more "why it's designed this way, how the code runs, and how the project gets deployed."
- **💼 Enterprise-level practice, targeting "able to deliver"**: Using Shopkeeper Data Q&A, Deep Research, Shopkeeper Knowledge Base, and E-commerce Assistant as the main threads, connecting intent parsing, multi-source knowledge, human handoff, review, and monitoring; putting **multi-route retrieval, evaluation, observability, cost, and guardrails** into real-world contexts for practice. Writing resumes and presenting projects becomes grounded rather than vague.
- **✅ Every case is measured by "it can actually run"**: Not just explaining concepts or pasting pseudo-code, but providing **runnable cases, source code, environment instructions, and common troubleshooting** wherever possible. All case content has been organized based on actually verified runs, helping you avoid pitfalls and get up to speed quickly.
- **📚 Tutorials, source code, and interviews—a three-in-one that actually works**: Not just "finished reading," but also "can run it" and even "can answer it"—**runnable cases and source code**, **prompt templates**, and deployment approaches, refusing to "only talk concepts." The interview question bank breaks down questions by **common competency domains from training programs and JDs**, with a significant portion organized from **real interview questions at major companies**, public interview experiences, and high-frequency follow-up scenarios, suitable for career changers and new graduates to review intensively.
- **🚀 Facing 2026, continuously evolving and hardcore**: The tech stack and high-frequency question patterns will iterate with the ecosystem, aligning with the dimensions of ten-thousand-yuan-level training curricula for "AI Application Development Engineers"; it's not just telling you "what to learn," but also "how to do projects, how to present projects, how to answer interviews." ## 🚀 Quick Start

Learn together with the [online documentation](https://didilili.github.io/ai-agents-from-zero/#/). Want to run a case immediately? Follow the steps below. For more detailed environment instructions, API applications, and common error handling, see [Getting Started and FAQ](%E6%96%B0%E6%89%8B%E5%85%A5%E9%97%A8%E4%B8%8E%E5%B8%B8%E8%A7%81%E9%97%AE%E9%A2%98.md).

1. **Clone the repository and enter the project directory**

   ```bash
   git clone https://github.com/didilili/ai-agents-from-zero.git
   cd ai-agents-from-zero
   ```

2. **Prepare the environment** (Python 3.10 recommended, supports 3.10–3.13)

   ```bash
   python3.10 -m venv .venv
   source .venv/bin/activate          # macOS/Linux
   # .venv\Scripts\activate           # Windows CMD
   pip install -r requirements.txt
   ```

3. **Configure API Key**
   - Copy `.env-example` from the root directory to `.env`
   - Fill in your API Key in `.env` (such as Qwen/Alibaba Bailian, DeepSeek, etc.). The variable names must match the code (such as `aliQwen-api`, `QWEN_API_KEY`, `deepseek-api`)
   - For how to apply for keys on each platform, see [Getting Started and FAQ - How to Apply for Keys on Various API Platforms](%E6%96%B0%E6%89%8B%E5%85%A5%E9%97%A8%E4%B8%8E%E5%B8%B8%E8%A7%81%E9%97%AE%E9%A2%98.md#_5、各-api-平台如何申请-key？)

4. **Run the first case in the project root directory**

   ```bash
   python 案例与源码-2-LangChain框架/01-helloworld/StandardDesc.py
   ```

   **Suggestion**: Run `python` in the **project root directory** for unified management of the virtual environment, dependencies, and output files. `load_dotenv()` in regular scripts usually automatically searches upward for `.env`; if you are using an IDE, REPL, or debugger and cannot read the Key, check its working directory configuration. If you do not want to use cloud APIs, you can use the [Ollama local model](%E6%96%B0%E6%89%8B%E5%85%A5%E9%97%A8%E4%B8%8E%E5%B8%B8%E8%A7%81%E9%97%AE%E9%A2%98.md#_54-不想用云-api：用本地-ollama（无需-key）) (no Key required).

If you encounter `ModuleNotFoundError`, API Key errors, cannot find `.env`, etc., see [Getting Started and FAQ - Common Problems and Solutions](%E6%96%B0%E6%89%8B%E5%85%A5%E9%97%A8%E4%B8%8E%E5%B8%B8%E8%A7%81%E9%97%AE%E9%A2%98.md#_6、常见问题与解决).
